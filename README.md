# Infiltracion (Abel Alex Callahuara LU: 839 )
## Descripcion del juego:
Prototipo Mecanico para simular un espia infiltrandose en una base secreta donde intenta recojer informacion sin ser atrapado por los guardias
## Controles: 
* Movimiento:
	* Adelante: W
	* Atras: S
	* Izquierda: A
	* Derecha: D
	* Salto: Tecla Espacio/Space
 ## Opcionales elejidos:
* Opción C (Trampa de Rayo Láser / Fuego Continuo)
* Opción B (Power-Up de Invisibilidad)
* Opción D (Zona de Desaceleración / Barro)
